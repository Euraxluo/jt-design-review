# 示例：API 访问审计（绿地场景）

一个虚构但完整的方案确认原型——给 Go + PostgreSQL 单体服务加「API 访问审计」功能。
打开 `preview.html`（或 `node ../../scripts/build.mjs spec.json` 重新构建）即可体验：

- **界面改动**：审计日志新页（侧栏导航 + 筛选栏 + 记录表 + 详情抽屉）——绿地场景，无 htmlBefore
- **系统流程**：审计链路泳道（emit → 批量落库 → 查询 → 每日清理）
- **数据库变更**：新表 audit_logs（完整 DDL/迁移/回滚）+ users 语义变化（列不变）
- **中间件变更**：决策块「不引入 Kafka」+ 量化依据 + 清理 job
- **后端变化**：3 个新接口
- **反馈**：2 个待确认问题（body 可见性 / 保留期）

试一试：点表格任意元素写批注 → 「反馈」tab 看汇总 → 点「复制反馈」。
